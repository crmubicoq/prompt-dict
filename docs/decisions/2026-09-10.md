## 5. `updatedAt` — "수정"의 범위

### `editCategory` 개명은 갱신하지 않는다
의미상 근거: 소속은 그대로고 라벨만 바뀐다.

**실용적 근거가 더 크다** — 카테고리 하나를 개명하면 거기 속한 프롬프트
전부가 같은 `updatedAt` 을 갖는다. 150개 중 100개가 같은 시각이 되면
**수정순 정렬이 통째로 무너진다.**

### 즐겨찾기 토글도 갱신하지 않는다
즐겨찾기를 수정으로 치면 별 하나 누를 때마다 `allPrompts` 를 저장해야 하고,
그건 **T-118에서 떼어내려는 두 키 동시 저장을 되살린다.**
의미상으로도 즐겨찾기는 프롬프트의 속성이 아니라 내 북마크다.

두 태스크를 따로 보면 놓칠 연결이었다.

### 마이그레이션 대신 폴백
`updatedAt || createdAt` + `promptUpdatedAt()` 헬퍼.

`createdAt` 복사는 **거짓을 기록한다** — "생성 시각에 수정됨"이
진짜 수정과 구별되지 않는다. **부재가 곧 정보다** ("수정된 적 없음").
33개 전체를 다시 쓰는 작업이라 실패 가능성도 생긴다.

롤백 시 `updatedAt` 이 `undefined` 였으면 **키 자체를 삭제**해
"수정된 적 없음"으로 정확히 되돌린다.

## 13. ★ 프로브가 세 번 거짓말했다

이번 세션에서 검증 자체가 틀린 답을 낸 사례가 셋이다.
**패턴이 같다 — 관측 지점이 작업 경계보다 앞이면 프로브가 조용히 통과시킨다.**

### T-126 — `sleep(400)` 이 패치 전에도 PASS
`--virtual-time-budget` 아래에서 `setTimeout` 은 가상 시계로 즉시 발화하는데
`FileReader` 는 실제 I/O 라 동기화되지 않는다.
**파일 읽기 완료 전의 DOM 을 측정했다.**

### T-128 — 제자리 변경을 완료 술어로 씀
`catOf('개발A') !== '개발'` 은 `await PromptStorage.save*` **이전**의
제자리 변경 직후에 참이 된다. `currentFilter` 이관과 `renderCategoryList` 가
아직 안 돈 **작업 중간 상태**를 쟀다.

### T-119 — 프로브 리터럴이 시드 데이터와 어긋남
프로브와 시드를 다른 heredoc 으로 쓰면 한글 리터럴이 서로 맞지 않아
거짓 실패가 난다.

### 규칙
- **고정 대기(`sleep`)를 쓰지 않는다.** 관측 가능한 조건 대기로.
  시간 초과는 FAIL 로 드러낸다
- **완료 신호는 그 작업이 끝났을 때만 참이 되는 것**이어야 한다.
  토스트나 최종 상태지 중간 변수가 아니다
- **검색·비교 대상은 리터럴로 쓰지 말고 실제 데이터에서 값을 꺼내 쓴다**

## 15. P3로 넘긴 것 — 잊으면 안 되는 것들

### ★ 동시 실행 가드 + 스냅샷 epoch
지금 롤백 규약은 **"쓰기가 동기"라는 전제** 위에 있다.
`localStorage` 는 동기라 `await` 가 마이크로태스크 한 틱만 양보하지만,
`fetch` 로 바꾸는 순간 그 틈이 수백 ms 가 된다.

```
t0  A 별표 → 스냅샷 {} → favoriteIds={A} → await (300ms, 루프 열림)
t1  B 별표 → 스냅샷 {A}  ← 이미 오염된 것을 스냅샷
t2  요청1 실패 → favoriteIds={}  ← B의 변경까지 지워진다
t3  요청2 성공 → 서버 {A,B}, 메모리 {}  ← 조용한 불일치
```

저장 호출 지점 26개 중 가드가 있는 곳은 `bulk.js` 하나뿐이다.
**어댑터 교체와 같은 태스크에서** 넣어야 한다.
별도 태스크로 미루면 그 사이 릴리스가 조용히 깨진 상태다.

### ★ 저장 입자 크기
`savePrompts(list)` 는 컬렉션 통째 쓰기다. 팀 서버에서 두 사람이 동시에 쓰면
나중 사람이 앞사람 것을 덮는다.
레코드 단위 엔드포인트로 갈지 **스키마 짜기 전에** 정해야 한다.
나중에 바꾸면 저장 호출 25곳을 전부 다시 만진다.

### 이미지 다중화
`thumbnailImage` 는 문자열 하나다. 배열로 바꾸면 내보내기 스키마·파서 3종·
렌더 3곳·`thumbnail.js` 전부가 바뀐다.
권고: **`images` 를 별도 테이블(FK)로 만들어두되 UI 는 1장만 노출.**
스키마는 열어두고 화면은 안 건드리는 쪽이 되돌리기 싸다.
